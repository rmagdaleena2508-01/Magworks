Tribezo

A browser game where you talk to Zazo, the leader of an island whose language is English with every word reversed. Benji the translator flips your words with a stack — my DSA project, turned into a real app.

Play it live Code
Live · a real C stack, compiled to WebAssembly, running in your browser

Where it started

It began as my DSA (Data Structures and Algorithms) project. I kept coming back to the stack — a stack can turn a word around, but on its own that felt too small for a whole project.

Then I remembered movies with tribes who speak in reverse: their words sound strange, but make sense once you flip them. What if an island tribe only spoke in reverse, and a stack was what let you talk to them? That's how Tribezo started, right there in class.

How it works

You type in English. Benji, the translator, flips your words with a stack and tells Zazo, the island's leader. Zazo answers in Calonis — English with the letters of every word reversed — and Benji tells you what he said. Zazo can even show you around the island.

The stack is written in C (backend/src/stack.c) and compiled to WebAssembly, so the real C data structure runs right in your browser every time a word is flipped. One stack is made per message and reused for each word, so it's empty and ready for the next. Letters outside a–z (like é) keep their place.

Key engineering decisions

  • The DSA core is real, not faked. The flipping is done by a C stack compiled to WebAssembly and run in the browser — not a one-line JavaScript reverse. The point of the project was to actually build and use the data structure.
  • Zazo's replies are generated, with an honest fallback. Gemini writes Zazo's answers through a small Vercel function; if the AI isn't available, Zazo uses a fixed set of replies, and the history panel labels every message as "answer by Gemini" or "fixed answer (AI not available)".
  • Safe by default. The AI function only answers Tribezo's own sites, limits each visitor to 8 messages a minute and 300 a day, uses a key with billing turned off, and keeps nothing after you leave — no database, the key never reaches the browser.
  • Shipped twice, and debugged for real. It runs on both Vercel and GitHub Pages. Getting the live GitHub Pages site to use Gemini meant wiring it to the Vercel function across hosts and fixing the deploy config — documented the whole trail in the README.
